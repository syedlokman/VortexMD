# VortexMD UI/UX Specification (v1.0 Frozen)

> Developer DOM, CSS, and interaction contract for the presentation layer (`index.html`, `src/index.css`, `src/ui/**`).
> For user-facing feature walkthroughs, see [Player & Controls](player-and-controls.md) and [RMSD & 3D Measurements](rmsd-and-measurements.md).
> **Status: FROZEN (v1.0)** — UI changes require updating this spec first.

## 1. Presentation Rules & Stack

- **Strict Decoupling**: UI communicates with `<vortexmd-engine>` only through `PUBLIC_API` and `EVENTS` (`npm run check:boundaries`).
- **Fault Isolation**: Every panel mounts via `mountPanel(name, init, engine)` (`src/ui/shell/boundary.js`). Five faults within 10 s abort that panel alone and show a toast without disrupting playback or sibling panels.
- **Scoped Listeners**: All listeners use the injected `listen(target, type, fn)` (AbortController-scoped). Raw `addEventListener` is banned outside `boundary.js`, `toast.js`, and `DOMContentLoaded` in `app.js`.
- **Zero-Framework Stack**: Tailwind CSS v4 (`@utility` classes in `src/index.css`), Lucide icons (`refreshIcons()`), and native `<dialog>` / Popover API.

## 2. Layout Regions & Selectors

| Region | Selector | Specification |
| :--- | :--- | :--- |
| **Left Sidebar** | `#sidebar[data-collapsed]` | `18rem` expanded / `4rem` collapsed (`.when-expanded` / `.when-collapsed`). Manual toggle only; mini buttons highlight dark with status dots when files are loaded. |
| **3D Viewport** | `<vortexmd-engine id="player">` | Shadow DOM containing only `#viewport`. Accepts file drag-and-drop (`FILE_DROPPED`). |
| **Right Minibar** | `#drawer-mini` | `70 px` strip with Display Manager shortcuts (Components, Measurements, RMSD), Fullscreen, and branding. Hidden while drawer is open. |
| **Right Drawer** | `#drawer` | `360 px` slide-in panel (Components, Measurements, RMSD tabs). Opening pauses playback. |
| **Player Bar** | `#player-ui` | Floating bottom-center; shifts left with `.settings-open` when drawer opens. `50%` opacity and non-interactive until a topology loads. |
| **Modals & Toasts** | `<dialog>`, `#toast-container` | Native dialogs (log, session overview, new-session confirm, re-link, sample files). Top-right toasts auto-dismiss in **4 s** (info/success), **8 s** (warning), **15 s** (error). |

## 3. Panel Modules & Rendering Invariants

| Module (`src/ui/panels/`) | Key UI Invariants |
| :--- | :--- |
| `loader-panel.js` | Trajectory input stays disabled until topology loads; loading a second topology triggers New-Session confirm; player bar unlocks on initial indexed frames (progressive TTFF). |
| `session-panel.js` | Uses File System Access API with `<input type="file">` fallback; missing files trigger the Re-Link dialog (atom-count mismatch = fatal error, filename mismatch = warning). |
| `player-bar.js` | Dual-track scrubber (dark = indexed, blue = played, dim masks = outside A/B loop, amber diamonds = delegated pin clicks); seeking past indexed frames clamps with a `2.2 s` lock tooltip; Row 2 pills generated by `templates.js`. |
| `display-tree-panel.js` | Empty molecular categories are not rendered; group toggles cascade to children; **Show All** dispatches a single atomic `engine.updateDisplay([], cfg)` call. |
| `measurement-panel.js` | Click-to-pick cancels automatically on `Esc`, tab switch, or drawer close. |
| `rmsd-panel.js` | Auto-stride caps output at $\le 2,500$ points; canvas chart supports click-to-seek, wheel zoom, and double-click/Reset. |
| `drawer.js`, `hotkeys.js`, `shapes-panel.js`, `log-modal.js` | `drawer.js` never queries `#player` directly; `hotkeys.js` ignores form inputs and blurs focused buttons on `Space` to prevent double-toggle. |

## 4. State, Security & Accessibility

- **Busy State (`ENGINE_BUSY`)**: Disables play, scrubber, and frame input while dimming `#player-ui`.
- **Surface + Playback**: Active `Surface` representation pauses playback with an info notice recommending `Spacefill` (`Sp`).
- **Validation Reset**: Mismatched trajectory triggers `TRAJECTORY_INVALID`, error toast, and progress UI reset.
- **XSS & A11y**: All user/file-derived strings interpolated into HTML pass through `escapeHtml()` (`dom-utils.js`); icon-only buttons carry `aria-label`; drawer tabs use `role="tabpanel"` / `aria-labelledby` with arrow-key navigation.

## 5. Design Tokens & Protected Test Hooks

- **Palette & Style Codes**: Primary `blue-600/700`, success `emerald`, error `rose/red`, warning `amber`, neutrals `slate`; chain/lipid palettes live in `src/contracts/display.js`. Style codes: `Ca Li Su BS Sp Hy HT Rb Tu Rp Rk Ba Ln Pt Bb Tr`.
- **Protected DOM Hooks** *(do not rename without updating tests & benchmarks)*:
